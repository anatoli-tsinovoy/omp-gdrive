`gdrive://<drive>/<folder>/<file>`: Google Drive as read-only files for read/glob/grep, by names (`My Drive` or a shared drive's name first); bare lists drives. Google files end in .gdoc/.gsheet/.gslides; a .gsheet reads as every tab in TSV; colliding names carry `~<id>`. `gdrive://id/<id>` opens any item by id; `gdrive://search?q=<words>&kind=doc|sheet|slides|pdf|folder|image` searches. grep fetches each file it walks: scope it to a folder. Edits go through `xd://gdrive`.
